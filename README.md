# Conversie monedă

Aplicație Flutter care transformă o sumă între `RON`, `EUR`, `USD`, `GBP` și `CHF` folosind cursuri fixe raportate la RON.

## Rulare

1. Instalați Flutter SDK și adăugați comanda `flutter` în `PATH`.
2. Din directorul proiectului rulați `flutter create .` pentru fișierele de platformă.
3. Rulați `flutter pub get`, apoi `flutter run`.

Cursurile se află în mapa `_ratesToRon` din `lib/main.dart`.
